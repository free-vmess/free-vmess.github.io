  • 规则模式（Rule）：推荐新手使用。Clash会根据预设规则自动判断哪些流量走代理，哪些直连。
  • 全局模式（Global）：所有流量均走代理，适合需要统一IP的场景（如访问被封锁的网站）。
  • 直连模式（Direct）：关闭代理，仅作为本地HTTP服务器使用。

在配置文件的rules部分，你可以添加： yaml - DOMAIN-SUFFIX,google.com,Proxy - DOMAIN-SUFFIX,baidu.com,DIRECT 这样，访问Google时走代理，访问百度时直连，既保证速度又节省流量。

Q1：免费Clash URL会不会窃取我的隐私？

答：风险确实存在。公共节点可能记录你的访问日志，甚至篡改网页内容。建议： - 避免在免费节点上登录网银、邮箱等高敏感账户。 - 使用HTTPS加密的网站（地址栏有“锁”标识）。 - 有条件时，优先选择自建节点或付费服务。

Q2：为什么我导入URL后，节点列表是空的？

答：可能原因： 1. URL已失效（节点全部下线）。 2. 网络环境无法访问该URL（需先开启代理）。 3. 配置文件格式错误。可尝试用浏览器打开URL，检查是否为合法YAML格式。

Q3：Clash和VPN到底有什么区别？

答：核心区别在于工作方式： - VPN：加密所有流量，操作系统层面接管，对应用透明。 - Clash：基于HTTP/SOCKS5代理，仅处理指定流量，更灵活，但需应用支持代理设置。简单说，VPN适合“傻瓜式”全场景加密，Clash适合“精细化”分流管理。

Q4：免费节点能用多久？

答：取决于分享者的维护意愿。公益节点通常存活数天至数周，而自建节点可持续数月。建议同时收藏3-5个订阅源，轮换使用。

Q5：如何判断一个订阅链接是否“干净”？

答：可通过以下方式： - 在VirusTotal上传URL进行恶意代码扫描。 - 查看配置文件中节点名称是否包含可疑字符（如“广告”、“统计”）。 - 使用Clash的“日志”功能，观察是否有异常连接请求。

FAQ

Surfboard 策略组如何提升在线视频体验？
Surfboard 可通过策略组将视频流量分配到低延迟、高带宽节点，自动切换到最佳节点，减少缓冲和卡顿，提高在线视频播放的流畅性和整体网络体验。
V2Ray 的 DNS 模块如何提升解析速度？
V2Ray 内置 DNS 模块支持并行解析，可同时请求多个上游 DNS 服务器。用户可配置本地优先解析或远程解析策略，从而减少域名污染与延迟问题。
VMess 的加密方式如何选择？
VMess 支持自动加密和 AEAD 加密等多种方式。AEAD 加密更安全且抗重放攻击，适合高安全性需求的网络环境，而普通加密在性能上稍快，但安全性略低。
Nekobox 如何设置分流规则？
Nekobox 提供图形化规则编辑界面，可基于 IP、域名、地区等条件创建分流规则。例如可设置国内直连、国外代理、特定网站走特定节点，操作直观。
如何在路由器上使用 PassWall2 为不同设备设置不同策略？
在 PassWall2 的规则或策略组中为固定 IP 或 MAC 地址创建特定路由条目，将其映射到不同的策略组（如工作机走直连、游戏机走低延迟节点），并保存规则后重载以生效。
Nekoray 如何导入 V2Ray 节点？
打开 Nekoray 客户端后，点击“导入配置”，选择 V2Ray 或 Clash 类型的订阅链接。程序会自动解析节点列表，用户可一键连接或进行延迟测试。
Nekoray 支持 Trojan 吗？
支持。Nekoray 基于 sing-box 核心，能兼容 Trojan、Vmess、Vless、Hysteria2 等多种协议。用户可在同一界面中管理和切换不同类型节点，非常方便。
VLESS + XTLS 模式适合高并发环境吗？
适合。XTLS 去除冗余加密，提高 CPU 使用效率，降低延迟。结合策略组和多出口节点，可在高并发或多连接场景下保持稳定、高速的网络体验。
Matsuri 节点延迟排序功能如何使用？
Matsuri 定期测速节点延迟，并结合策略组自动选择延迟最低的节点。用户无需手动切换节点，即可保持高速访问，提高网页、视频和游戏体验的稳定性。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
